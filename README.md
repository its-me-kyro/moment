## ✨ Features

| | |
|:--|:--|
| 🕐 **Clock** | Timezones, fonts, 12/24h, hide date / weekday / seconds / zone |
| ⏳ **Countdown** | New Year, Christmas, stream & event presets, custom target |
| ⏱️ **Stopwatch** | Start / pause / resume, laps, centiseconds, movable controls |
| 💬 **Message** | Big auto-fit text, AFK / BRB shortcuts, zoom |
| 🎴 **Flipboard** | Animated split-flap digits on Clock & Stopwatch |
| 🎨 **Themes** | 11 built-in looks + custom image / GIF background |
| 🧘 **Zen mode** | Eye icon hides UI — click anywhere to bring it back |
| ⛶ **Fullscreen** | One-tap fullscreen (desktop & mobile) + exit control |
| ☀️ **Quick theme** | Sun / moon toggle between light and dark |
| 💾 **Persistent** | Everything saved in `localStorage` |

## 🎴 Flipboard

Mechanical split-flap digits with hinged flip animation.

**Design presets** (one click):

| Classic | Airport | Neon | Gold |
|:-------:|:-------:|:----:|:----:|
| dark slate | departure board | cyan glow | amber / brass |

| Minimal | Inverse | Ocean | Carbon |
|:-------:|:-------:|:-----:|:------:|
| soft gray | light cards | teal blue | matte black |

Fine-tune **digits**, **top flap**, **bottom flap**, and **seam** colors anytime. Size & position controls apply to the flipboard too.

## 🎨 Themes

`Dark` · `Light` · `Midnight` · `Ocean` · `Forest` · `Sunset` · `Violet` · `Slate` · `Rose` · `Paper` · `Custom`

```bash

```
